# HERE Technologies Documentation | HERE Docs Documentation

> Official HERE developer documentation for building location-aware applications with HERE APIs and SDKs. Access guides, tutorials, code samples, API references, and data schemas for maps, routing, search, geocoding, and location intelligence.

Append .md to any documentation page URL to get its markdown version.

Each project below either links to its own llms.txt, which contains a full index of that project's documentation, or inlines the index its authors wrote by hand. Where links are listed, the section and category ones narrow to that part of the docs.
